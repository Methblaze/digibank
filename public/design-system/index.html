How it works

When I rebuilt Digi Bank as a working web app in 2026, I moved its colours, type and clay shadows into one token source, so the Tailwind theme and the Figma file are made from the same values.

  1. One source

    Every colour, size, font and shadow is written once, in the open DTCG token format, in tokens/*.json.

  2. Code and Figma

    A build turns it into CSS variables and JavaScript for the app, and into Figma variables, text styles and effect styles for the design file.

  3. Proved, not trusted

    A check runs on every change: names and references, WCAG contrast for every text and control pair, and no drift between Figma and the code.
